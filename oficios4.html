📘 README · v4

Qué es

Fábrica de agentes declarativos. Configuras, aplicas, previsualizas y exportas un HTML autónomo con el player y los datos embebidos. El exportado funciona con doble clic, sin red, sin CDN.

Flujo

  1. Edita los datos en "Datos del agente".
  2. Ajusta dimensiones.
  3. "Aplicar configuración" → se guarda y previsualiza.
  4. "Exportar player como HTML" → descarga HTML autónomo.

Modos

  • index.html → editor + preview.
  • index.html#player → solo player.
  • HTML exportado → detecta window.AGENT_CONFIG y arranca en modo player.
